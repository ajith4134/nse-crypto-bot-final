## 2. FreqUI false-alarm (root-caused, NOT a bug)
- QA first hit `:8080/` → **blank white page**, 6 `MIME type text/html` module-script errors.
- Cause: FreqUI is built with base `/frequi/`; its `index.html` requests `/frequi/assets/*.js`,
  but Freqtrade serves assets at root `/assets/*` and its `_redirects` (`/* /index.html 200`)
  returns HTML for the unmatched `/frequi/` path → MIME error → app never mounts.
- The **real** path is the Caddy gateway `:8100/frequi/` (what public users hit) →
  assets return `application/javascript` 200 → app mounts fully. FreqUI is HEALTHY.
- Action: capture FreqUI via `:8100/frequi/`, not `:8080/`, in future runs.
