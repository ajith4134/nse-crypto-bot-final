# Ultra-Network Frontier — Phase-1 SELECT research (2024–2026)

Purpose: mechanisms to steal for the NEW ultra-advanced network where **each neuron is a full ML model**
(320+ heterogeneous frozen experts, differentiable MoE gates, deep cascade, dynamic attention I/O bus,
Leiden-community hierarchical routing, DARTS structure search, brain trust ledger). CPU-first.
Traceability target: `research/video/MASTER-REQUIREMENTS.md` (211 REQs → 63 CANONs).

Method: Phase-1 selection only (README/abstract signals; no cloning, no source reading). Star counts
approximate from search snippets; confirm at integration time.

Verdict key: **steal-mechanism** = take the idea/algorithm, implement in our stack · **pip** = install and
use directly · **vendor** = clone into `vendor/` and adapt · **skip** = not for this phase.

## MECHANISMS TO STITCH INTO THE INVENTION (synthesis, mapped to CANON ids)

The invention = a **trainable graph of frozen model-neurons** where the LEARNED substance lives entirely in
the glue: gates, edges, cascade depth, trust, and heads. Six mechanism packs, each traced to CANONs:

**1. The gate — hybrid data-free + trained router over 320 frozen experts** (CANON-58 ensembles/leaderboard, CANON-61 CPU budget)
- Bootstrap every node's router entry with an **Arrow-style data-free prototype** (statistics of the node's own parameters/outputs) + a **PHATGOOSE-style per-expert sigmoid gate** trained post-hoc — a working router before any joint training, new nodes join the graph instantly.
- Keep **SMEAR-style soft merging** for homogeneous sub-pools (dense gradients to the gate) and **mergekit TIES/DARE** (pip, CPU) as the primitive when the gate decides to merge rather than select.
- **HMoE cost-aware load-balance loss**: bias the gate toward cheap experts — the differentiable form of our CPU-first constraint (CANON-61).
- **Twin-Merging decomposition**: factor out the shared "market-common" prediction so gates only route residual disagreement — lower router variance across 320 nodes.

**2. The topology — label-free evolvable graph, NEAT-bounded** (CANON-20 evolvable topology, CANON-59 GA-only-where-no-label, CANON-41 mark-to-market fitness, CANON-34 topology search protocol)
- Core learner: **GPTSwarm REINFORCE edge optimization** — inter-node edges as learnable probabilities optimized against black-box mark-to-market PnL reward. This IS the "NEAT-style evolvable topology bounded to label-free search" the videos require, in its best modern form.
- Population lane: **NEAT speciation + innovation numbers** (neat-python reference, TensorNEAT for vectorized runs; EXAMM for the time-series-specific operator set), fitness = CANON-41 (realized+unrealized PnL × underwater minimization). **EvoTorch (pip)** supplies CMA-ES/PGPE over gate/topology params in our exact PyTorch stack; **LoraHub-style CMA-ES over mixing coefficients** is the same trick at the gate level.
- Grow/prune: **SENN natural-gradient expansion trigger** decides WHEN to add a node/edge, **GradMax init** adds it without disturbing current outputs, **GHN/LoGAH warm-start** predicts its initial gate weights from graph position (RBT-05 "complexity is a displayed scalar" falls out for free).
- Budget shield: **zero-cost NAS proxies (zero-cost-nas / AZ-NAS)** rank candidate topologies in one pass before any PnL backtest is spent (CANON-43 anti-overfit telemetry: count backtests). **LLMatic MAP-Elites archive** keeps a diverse topology reserve per regime; **MaAS supernet sampling** picks a subgraph per query/regime.

**3. Conditional compute — harder inputs get more experts, easy inputs exit early** (CANON-61 CPU budget, CANON-49 dead-band abstention, CANON-51 per-bar loop)
- Zero-training backbone TODAY: **Agreement-Based Cascading + PABEE patience** — tier-1 cheap experts vote; agreement → emit signal, disagreement → escalate to the deep column. Works over black-box sklearn/xgboost nodes immediately.
- Differentiable form: **Mixture-of-Depths top-k capacity routers** per cascade layer (trained with existing MoE-gate gradients) + **ACT halting** for per-column depth; **Mixture-of-Recursions** re-applies the same expert block N times where depth beats width.
- Honesty-grade exits: **CALM Learn-Then-Test calibrated thresholds** fused with the existing crepes conformal gate (Pillar 17) → early exits carry statistical guarantees; **L2D/JEI-DNN learned rejector** and the **Zellinger early-discard branch** implement CANON-49's dead-band "stay flat" as a first-class routing outcome.
- Budgeting: **FrugalGPT quality-scorer cascade + Cascadia SLO solver** distribute the per-tick CPU budget across symbols (hard symbols get more experts); **MSDNet anytime heads** guarantee a valid signal at ANY cutoff (CANON-51 per-bar loop never blocks).

**4. New neuron classes — the CPU-first node zoo expansion** (CANON-17 LSTM lane, CANON-18 encoder transformer, CANON-19 causal TCN, CANON-22 multi-model family, CANON-26/27 targets, CANON-21 future lane)
- Pip-now node types: **TinyTimeMixers** (1M-param pretrained forecaster, sub-100ms CPU), **Chronos-Bolt small** + **TabPFN-TS** (zero-shot quantile nodes feeding the conformal gate), **ncps CfC** (liquid continuous-time regime trackers), **pytorch-tcn streaming mode** (THE causal-TCN requirement CANON-19, with per-tick stateful inference), **minGRU/minLSTM** (modern CANON-17 lane), small **xLSTM** configs.
- Steal-block types: **ModernTCN** DWConv large-kernel block, **thuml Time-Series-Library** as the selective vendor hub for PatchTST/iTransformer/TimeXer (CANON-18 lineage), **TKAN/TimeKAN** for frequency-decomposed nodes. Mamba only via **mambapy** (official kernels GPU-only — honest CPU-fit 6). TimesFM/Moirai only as rare tier-3 deep experts behind the cascade.
- **KAN goes in the GATES, not the nodes**: efficient-kan KANLinear replaces nn.Linear inside routers/heads — learnable-activation expressiveness where parameter counts are tiny, so gate capacity rises at negligible CPU cost.

**5. Training signals for a graph of black boxes — no backprop through neurons** (CANON-14 credit assignment reinvented, CANON-31 training discipline, CANON-59 label-free boundary)
- **Direct Feedback Alignment (BioTorch/DRTP)**: broadcast the realized trade-outcome error through fixed random projections directly to EVERY gate/glue layer in parallel — trains the whole graph without any gradient through frozen experts. This is the single most important enabler of "each neuron is a full ML model".
- **Forward-Forward local goodness** per gate layer and **predictive-coding error neurons (ngc-learn concepts, Predify wrapper)** for test-time iterative refinement around frozen columns — local signals = the modern answer to CANON-14's credit-assignment requirement at graph scale.
- **DSPy pattern** at the outermost level: compile the whole pipeline's thresholds/configs against the end scorecard metric by black-box search — the same philosophy as CANON-31's "gradient where labels exist" with CANON-59's "search where they don't".

**6. The meta-controller — per-regime trust + champion swapping** (CANON-06 timeframe arbitration, CANON-41 fitness, CANON-42 rolling accuracy, CANON-52 per-venue identity, CANON-58 leaderboard)
- Conditioning vector: **jumpmodels online soft regime probabilities** (persistence-penalized, flap-free; hmmlearn kept as baseline) feed both the MoE gates and the trust ledger; **RHINE-style regime FORECASTING** lets the router switch expert pools ahead of transitions; **Ada-MoGE trick**: feed the drift statistic itself into the gate.
- Trust update: **AdaHedge/EXP3 multiplicative weights on realized per-node trading loss** (~10 lines, regret-bounded) with **BOCD run-length collapse** as the "reset ledger to regime prior" trigger; **DESlib competence-region selection** (local k-NN accuracy) is the finer-than-regime trust layer — and per our own memory the path to beat stacking.
- Drift hygiene: **river ADWIN per-expert** (only drifted experts get down-weighted/retrained, never the whole network) + **Frouros input-drift** early warning (CANON-42 rolling accuracy over time, operationalized).
- Who trains online: **FLAML ChaCha champion–challenger** (k live challengers per regime among 320 nodes) + **qlib OnlineTool champion-swap + rolling retrain cadence**; **RD-Agent(Q) bandit scheduler** decides which node family the self-evolve loop spawns/retrains next; **FinRL softmax-over-rolling-Sharpe** as the robust fallback weighting; **OneNet OCP+RL combiner** as the differentiable online-gate template.

**7. Forecasting heads — both lanes the videos demand** (CANON-47 autoregressive rollout, CANON-48 direct multi-horizon, CANON-26/27 both target types, CANON-36 persistence gate, CANON-44 regression harness, CANON-49 sizing)
- Two heads per forecasting column, meta-selected per horizon/regime using the **2025 epistemic direct-vs-recursive decision rule**: (a) **Chronos-Bolt-style direct horizon×quantile tensor head** (default: one pass, no exposure bias — CANON-48/KRF-22), built with **NeuralForecast MQLoss adapter + MQ-RNN horizon-embedding branches + N-HiTS hierarchical interpolation**; (b) **TimesFM-style long-output-patch AR rollout** (128 candles per decode step — CANON-47/KRF-18 without per-candle error compounding). **skforecast's dual Recursive/Direct API** is the wrapper pattern for every sklearn-ish node.
- **Path-space decisions**: sample N trajectories (Chronos token sampling / quantile-path bootstrap) and trade on P(TP-before-SL), expected path drawdown, path-consistent inverse-vol sizing (CANON-49) — not marginal point forecasts.
- If AR fine-tuning is ever needed: **SoTra soft-token differentiable rollout** over scheduled sampling (keeps rollout differentiable for gate training).
- Evaluation law: **GIFT-Eval/fev-bench protocol** — rolling-origin multi-window backtests, per-horizon error curves, and per-horizon **persistence + DLinear floors** every head must beat before earning trust-ledger weight (CANON-36 enforced per horizon; **Darts conformal wrapper** pairs with the crepes gate for calibrated intervals, CANON-44).
