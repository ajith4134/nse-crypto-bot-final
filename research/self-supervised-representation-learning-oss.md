# Self-Supervised / Contrastive / Generative Representation Learning on Financial Time-Series + L2 Order Book — OSS SELECT (Phase 1)

Goal: a net whose hidden layers INVENT abstract features from raw market perception (OHLCV windows + L2 order book), CPU-first, PyTorch/sklearn/numpy. README/signals only — no source read.

Note on CPU-fit: a `--gpu` flag is only a device selector; all PyTorch models below run on CPU. "CPU-fit" here rates *practical* CPU training/inference given model size and data footprint (light CNN/patch encoders = high; 100–700M foundation models = low for training, ok for frozen inference).

## Recommendation — STITCH THESE 4 (+1 order-book branch)

No single repo covers both OHLCV *and* L2 order book with CPU-first probeable latents, so build a two-branch self-supervised feature inventor and stitch:

1. **TS2Vec** (`yuezhihan/ts2vec`) as the primary OHLCV-window encoder — light dilated-CNN, hierarchical contrastive, first-class `encode()` embeddings, trains on CPU. This is the backbone whose hidden layers "invent" abstract market features you can probe.
2. **tsai** (`timeseriesAI/tsai`) as the integration harness — gives MVP masked-reconstruction SSL, an encoder zoo (PatchTST/TST/InceptionTime), and embedding extraction so we don't hand-roll training loops.
3. **TF-C** (`mims-harvard/TFC-pretraining`) stitched in for a frequency-domain contrastive head — adds regime/spectral invariances TS2Vec misses, improving cross-market transfer.
4. **Order-book branch**: use **LOBench** preprocessing/baselines + a **DeepLOB** conv trunk as the L2 encoder, then fuse its embedding with the TS2Vec OHLCV embedding into one latent probed by the trading net.

Optional frozen "foundation" feature source: pull zero-shot embeddings from **MOMENT-small** or **Chronos-tiny** (`.embed()`) as extra channels — cheap on CPU since inference-only, no training. Treat β-VAE disentanglement as a torch reimplementation (skip TF1 `disentanglement_lib`) only if you later want explicitly disentangled market-state factors.
