# OSS candidates: order-book microstructure signals from depth snapshots

Goal: reusable Python feature computation (OFI, queue imbalance, book pressure, microprice, spread dynamics, VPIN/toxicity) over 5-level NSE (Zerodha) snapshots + full crypto books (ccxt fetch_order_book). README-level selection only (Phase 1); no code read.

Research date: 2026-07-02.

## Recommendation
Stitch: **lob-regime-scanner's `features.py`** (broadest snapshot-native coverage: multi-level OFI, imbalance, spread dynamics, VPIN, Kyle lambda in one module) + **mansoor-mamnoon/limit-order-book's `olob/microstructure.py`/`metrics.py`** (clean microprice/depth/impact analytics over standardized quote/depth frames) as the two code bases to adapt, with **flowrisk** pip-installed for rigorous VPIN-with-confidence-intervals from trade flow. Use hftbacktest's imbalance/microprice notebooks and the Multi-Level-OFI repo as math cross-checks for correct price-conditioned OFI on 5-level books.
