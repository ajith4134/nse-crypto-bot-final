## Recommendation

Stitch rather than pick one: **FinMem** is the reference architecture to copy (it is literally "record each trading decision with full context in layered memory, decay by importance, recall similar episodes, and re-weight memories by realized P&L" — small Python codebase, CPU-first, per-decision structured records), and **TradingAgents'** outcome-closure trick (each stored decision is later *resolved* with realized return + alpha and a one-paragraph reflection that gets injected into future prompts) is the cleanest self-reflection-on-outcomes loop in the wild. Concretely: store each brain decision (features, signals, decision_snapshot, reasoning) as a FinMem-style layered episode over your existing 85-column journal, retrieve with the Generative-Agents recency×importance×relevance score (reusing the HippoRAG/A-MEM associative memory already vendored in `memory/associative.py` as the retrieval backend), and close the loop with Reflexion-style verbal reflections written when trades close (Reflexion is already vendored). FinAgent's dual-level reflection (market-level vs decision-level) is worth mirroring conceptually but has no usable repo; mem0/Letta are heavier general infra that add little over what the project already has.
